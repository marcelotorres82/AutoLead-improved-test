# Modelo de evidência

Cada evidência possui tipo semântico, `FACT | INFERENCE | UNKNOWN`, claim, URL, publisher, datas, excerpt, confiança, qualidade da fonte, frescor, flag de verificação e soluções relevantes.

Fontes oficiais, governamentais, documentação e app stores recebem maior qualidade. Imprensa reconhecida fica abaixo de fontes primárias; diretórios e agregadores não justificam sozinhos uma oportunidade. Sem data, o frescor é conservador; acima de dois anos recebe peso baixo.

Ausência de detecção é `UNKNOWN`, não evidência negativa. Por exemplo, não detectar WAF jamais produz “a empresa não possui WAF”. Claims importantes na interface e no insight SDR mantêm link para a fonte.
